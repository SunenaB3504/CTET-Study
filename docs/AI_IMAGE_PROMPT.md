# AI Image Generation Prompts for CTET Prep Pal

## Hero/Splash Screen Background Image

### Primary Prompt (Recommended)

```
Create a professional, inspiring educational hero image for a CTET (Central Teacher Eligibility Test) preparation app called "CTET Prep Pal". 

Style: Modern, clean, professional with a warm and encouraging atmosphere
Color Scheme: Gradient from deep blue (#2563eb) to indigo (#4f46e5) with subtle purple accents
Mood: Inspirational, empowering, knowledge-focused

Key Elements:
- Abstract representation of learning and teaching excellence
- Subtle educational symbols (graduation cap, books, light bulbs, charts) integrated artistically
- Flowing, organic shapes suggesting growth and progress
- Gentle geometric patterns representing structure and methodology
- Soft glowing elements suggesting enlightenment and achievement
- Clean, minimalist design without clutter
- No text or typography (will be added separately)

Technical Requirements:
- Dimensions: 1920x1080px (16:9 aspect ratio)
- High resolution suitable for retina displays
- Smooth gradients and professional color transitions
- Professional UI/UX design aesthetic
- Space in the center for overlaying text and UI elements

Avoid:
- Cluttered compositions
- Overly literal educational imagery
- Stock photo aesthetics
- Cartoon or childish elements
- Heavy textures that would distract from overlay content
```

## Usage in App

The generated images should be:
1. **Optimized** - Compressed for web (WebP format recommended)
2. **Responsive** - Include 2x and 3x versions for retina displays
3. **Accessible** - Provide alt text descriptions
4. **Performant** - Keep file size under 200KB for hero images

## File Naming Convention
