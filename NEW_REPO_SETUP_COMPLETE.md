## ⚡ Troubleshooting

### If deployment fails:
1. Check Actions tab: https://github.com/SunenaB3504/Pass-CTET-Exam-easily/actions
2. Click on the failed workflow
3. Check the error messages
4. Common issues:
   - GitHub Pages not enabled → Enable in Settings > Pages
   - Workflow permissions → Settings > Actions > General > Workflow permissions → Read and write

### If site shows 404:
1. Wait 5 minutes (GitHub Pages can be slow first time)
2. Check Pages settings are correct
3. Verify deployment completed successfully
4. Try accessing with https:// prefix
